About FaceStyle AI

An innovation-driven, AI-based face shape estimation and personalized hairstyle recommendation platform developed as a Final Year (TY B.Sc. IT) project.

1. Project Objective

Choosing an appropriate hairstyle is traditionally based on intuition or salon trial-and-error. FaceStyle AI transforms this process by combining computer vision with cosmetological anthropometry.

The platform enables users to capture or upload portrait photographs, extracts 468 landmark coordinates using Google MediaPipe, calculates mathematical proportion ratios, classifies the face into one of six standard geometric categories, and recommends flattering hairstyles tailored to that geometry.

2. Technology Stack Architecture

  • Backend Framework: Python 3.12 & Django Framework (MVT Architecture).
  • AI / Computer Vision: Google MediaPipe Face Landmarker (468 3D vertices) & OpenCV.
  • Mathematical Analysis: NumPy Euclidean distance calculations & ratio heuristics.
  • Frontend Presentation: HTML5, CSS3, JavaScript ES6, Bootstrap 5, Font Awesome.
  • Database: SQLite3 (development) with strict MySQL schema compatibility.

Face Shape Estimation Pipeline

Stage 1
Acquisition & Preprocessing

Image acquired via HTML5 video stream snapshot or file upload. Validated for single face presence, resolution, and converted to RGB tensors.

Stage 2
468-Mesh Landmarks

MediaPipe Face Landmarker identifies 3D vertices including Trichion (10), Gnathion (152), Zygomatic arches (234, 454), and Gonion angles (58, 288).

Stage 3
Geometric Proportions

Calculates Face Length ($L$), Cheekbone Width ($W_c$), Forehead Width ($W_f$), Jawline Width ($W_j$), and relative dimension ratios.

Stage 4
Multi-Criteria Classification

Evaluates ratio matrices against calibrated thresholds to estimate Oval, Round, Square, Heart, Diamond, or Oblong archetype with confidence score.

Mathematical Formulations

During your college viva examination, explain these four primary geometric metrics calculated by ai_engine/measurements.py:

1. Face Length-to-Width Ratio ($R_{LW}$)

Ratio of vertical facial height to maximum cheekbone width:

R_LW = Face_Length / Cheekbone_Width
• Oblong: $R_{LW} > 1.48$ • Oval: $1.30 \le R_{LW} \le 1.48$ • Round/Square: $R_{LW} < 1.30$
2. Forehead-to-Jawline Ratio ($R_{FJ}$)

Calculates taper from temples down to jaw angles:

R_FJ = Forehead_Width / Jaw_Width
• Heart: $R_{FJ} > 1.25$ (distinct forehead prominence) • Square: $0.90 \le R_{FJ} \le 1.10$ (uniform box symmetry)
System Limitations & Ethical Responsibility

1. Geometry Heuristic Limitation: Human facial anatomy exists on a continuous spectrum; classification into discrete categories is an aesthetic styling guideline rather than a medical or genetic diagnosis.

2. Neutral Styling Guidance: FaceStyle AI does not make subjective beauty judgements or attractiveness scores. All styling recommendations focus purely on visual balance and personal confidence.

3. Privacy-First Architecture: Images uploaded by users are processed in memory and are never stored on external third-party cloud servers. Retaining photos in personal history is completely optional and can be deleted with a single click.
